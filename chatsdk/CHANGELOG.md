# Changelog

## 1.0.0

- Provide one OpenMLS implementation for direct and group end-to-end encrypted messaging.
- Provide reliable WSS mailbox delivery and HTTPS encrypted attachment chunks.
- Provide local encrypted storage, pending delivery queues, unread state, search, and seven-day retention enforcement.
- Provide reusable conversation, message, composer, emoji, sticker, media, and private-call UI boundaries.
- Support independent native OpenMLS libraries for Android, iOS, and macOS release artifacts.
- Publish the Flutter package under the unique `gmb_chat_sdk` package name.
